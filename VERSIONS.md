# Hilvert Versions

## None
No need to use "HV=".

  - Initial version
  - Answers must be separated by spaces

## HV=25.12

  - Answers can be separated by  number of commas and/or spaces

## HV=26.10

  - Grade depends on the item's difficulty: 1 point for easy items, 3 for
    medium and 5 for hard.

  - New flags: "--first" and "--last" to put an entire item in a whole page.

  - If not specified, default version if HV=26.10.
